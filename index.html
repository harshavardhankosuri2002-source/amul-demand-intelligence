Deployment & Launch Guide

Follow these instructions to run locally or deploy to GitHub and the cloud.

Option 1: Push to GitHub & Run with Streamlit Community Cloud (Recommended)

Streamlit is a stateful web application that requires continuous WebSockets. Streamlit Community Cloud connects natively to your GitHub repository for free 1-click hosting:

# 1. Create a new repository on https://github.com/new # 2. In your terminal, link and push to your GitHub repo: git remote add origin https://github.com/YOUR_USERNAME/amul-demand-intelligence.git git branch -M main git push -u origin main # 3. Visit https://share.streamlit.io, connect your GitHub account, # select repository 'amul-demand-intelligence', branch 'main', and main file 'app.py'.

Option 2: Deploy Landing Portal on Vercel

This repository includes vercel.json configured to deploy this clean web portal directly on Vercel:

# Deploy with Vercel CLI or via GitHub integration: npx vercel deploy --prod

Option 3: Run Full Interactive Dashboard Locally

# In Windows PowerShell: cd C:\Users\harsh\.gemini\antigravity-ide\scratch\amul-demand-intelligence pip install -r requirements.txt streamlit run app.py
